## What is PopOut?

PopOut is a Connect-4 variant played on a 7×6 board where four in a row wins. In addition to the standard *drop* move (placing a piece at the top of a column), players can *pop* a piece from the bottom of a column they own — shifting all pieces in that column down by one. This extra move dramatically expands the game tree and creates complex tactical situations.

## Agents

### MCTS (Monte Carlo Tree Search)

All MCTS variants share the UCT selection formula and differ in speed or correctness guarantees:

| Agent | Description |
|---|---|
| `StandardUCT` | Baseline pure Python UCT |
| `ExperimentalUCT` | Experimental heuristics on top of UCT |
| `SolverMCTS` | MCTS-Solver: marks terminal nodes as proven wins/losses |
| `ReuseSolverMCTS` | MCTS-Solver with tree reuse across turns |
| `NumbaMCTS` | Numba JIT-compiled engine, significantly faster |
| `NumbaSolverMCTS` | Numba + Solver |
| `FlatNumbaMCTS` | Flat (array-based) Numba MCTS |
| `FlatNumbaSolverMCTS` | Flat Numba + Solver |
| `ReuseFlatNumbaSolverMCTS` | Flat Numba + Solver + tree reuse |

### ID3 Decision Tree

An ID3 classifier trained entirely from scratch (no scikit-learn) on datasets generated by the MCTS agent. Two agent variants exist:

- **ID3Agent** — uses engineered board features + ID3 predictions, with forced-move detection for wins/blocks.
- **ID3AgentRaw** — same forced-move logic but feeds raw cell values to ID3.

## Installation

### Option A — Conda (recommended)

```bash
conda env create -f environment.yml
conda activate popout-ai
```

### Option B — venv + pip

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -e .[dev]
```

The `[dev]` extra adds `pytest` and `pytest-cov`.

## Running the Game

### GUI (Pygame)

```bash
python -m src
# or equivalently:
python play.py
```

Available modes from the main menu:

- **PvP** — Human vs Human.
- **Human vs AI** — choose difficulty (100 to 100 000 MCTS iterations, or a pre-trained ID3 model).
- **Arena** — Computer vs Computer with independently selectable agents.

### CLI

```bash
python -m src --cli
```

Move syntax: `d3` = drop into column 3, `p0` = pop from column 0.

Modes: 1) HvH, 2) HvC, 3) CvC tournament (configure agents and number of games).

### Notebooks

```bash
jupyter notebook notebooks/PopOut_Full_Report.ipynb
```

| Notebook | Purpose |
|---|---|
| `PopOut_Full_Report.ipynb` | Full technical report — main deliverable |
| `PopOut_Decision_Tree_Pipeline.ipynb` | ID3 pipeline: dataset generation, training, evaluation |
| `ID3_Decision_Tree.ipynb` | Warm-up exercise using the Iris dataset |
